### 05 &nbsp;·&nbsp; Crucible: Testing Sandbox for AI Agents

![In development](https://img.shields.io/badge/STATUS-In%20development-f59e0b?style=flat-square&labelColor=0d1117)

> Stress-tests AI agents under failure conditions and scores them honestly.

- **Fault injection:** timeouts, HTTP 429/500, malformed JSON, stale reads
- **Invariant checks:** refund exactly once, no over-refund, no out-of-scope access, request budgets
- **Honesty-based scoring** (100 / 50 / 0), YAML scenarios, web dashboard
